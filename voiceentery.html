    Voice Command Cheat Sheet (बोलने वाले कमांड)

    "Next" / "Agla" / "Aage" Moves selection cursor to next field.
    "Jama" / "Credit" / "Plus" Sets transaction type to Credit.
    "Kharcha" / "Debit" / "Minus" Sets transaction type to Debit.
    "Save" / "Submit" / "Jama Karo" Saves the current transaction into table.
    "Comma" / "Komma" Inserts a comma ( , ) into current text field.
    "Sunao" / "Read" / "Boliye" Reads aloud current form state via Speech Synthesis.

    Microphone Troubleshooting (माइक नहीं चल रहा?)

    1. Click "Request Mic Access" button in the voice status bar.
    2. Ensure browser site permissions allow Microphone access (HTTPS/Localhost).
    3. If using Chrome/Edge/Brave, check address bar mic icon to set to 'Allow'.
    4. If speech input is unavailable, use the Voice Input Simulator buttons below!
